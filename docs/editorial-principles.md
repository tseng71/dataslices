# 数据切片编辑原则

## 1. 先提出可回答的问题

每个故事只围绕一个核心问题展开，并通过若干递进问题建立完整叙事：现象、机制、空间差异、时间变化、后果与可行动方向。

## 2. 图形必须承担任务

每个可视化至少承担一种职责：

- 让读者感受一个尺度；
- 解释因果或机制；
- 支持比较；
- 暴露不确定性；
- 允许读者代入自己的位置或选择。

无法承担以上职责的图形应删除。

## 3. 不制造虚假精确

- 模型输出标为“估算”或“情景”。
- 公众观测与仪器测量分开呈现。
- 时间跨度不一致的数据不得拼接成一条无缝曲线。
- 只有在数据支持时才显示具体数字。

## 4. 阅读时长必须实测

页面完成后至少邀请五名首次阅读者测试。以活跃阅读时间中位数作为标注依据；不能通过拖慢动画人为拉长时长。

## 5. 研究过程可复核

每个故事目录必须包含：

- `story-design.md`：故事与可视化设计；
- `manuscript.md`：正文母稿；
- `methodology.md`：方法、假设、限制；
- `sources.md`：来源与访问日期；
- `data/`：能够公开再分发的数据或演示数据。
