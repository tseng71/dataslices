# 新故事目录模板

```text
stories/<slug>/
├── index.html
├── story.css
├── story.js
├── docs/
│   ├── story-design.md
│   ├── manuscript.md
│   ├── methodology.md
│   └── sources.md
├── data/
└── assets/
```

## 制作流程

1. 选题与核心问题
2. 证据链与数据可得性核验
3. 叙事结构与视觉语法
4. 正文母稿
5. 三个核心交互原型
6. 完整开发
7. 移动端与无障碍检查
8. 方法复核
9. 阅读时长测试
10. 发布与版本记录
