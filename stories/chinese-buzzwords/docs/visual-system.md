# 《从“给力”到“情绪价值”》视觉系统

状态：Stage 2 已确认；Stage 3 关键帧已验证  
日期：2026-07-28

## 1. 视觉名词

**词语本身。**

每个词条始终以真实中文文字存在，而不是先变成圆点、方块或无名粒子。字体、位置、轨道、边框和连接关系承担编码；词形与来源标签始终可恢复。

## 2. 视觉动词

**出现、放大、褪色、迁移、拆分、繁殖、留下。**

这些动作分别对应可说明的语言现象：

- 出现：进入某年官方观察记录；
- 放大：当前叙事或选中对象，不自动等同更高词频；
- 褪色：离开当前时间/证据窗口，不自动等同“无人使用”；
- 迁移：在另一语域观察到同一词；
- 拆分：从完整短语识别可复用结构；
- 繁殖：模板产生有证据的后续变体；
- 留下：回到档案时仍保有可核查痕迹。

## 3. 主题材料

### 主材料：屏幕上的活字

- 弹幕式横向进入用于开场和“网络出生”；
- 年份戳、来源角标和检索命中片段用于证据；
- 下划线、括号、占位符“××”和删除线用于结构分析；
- 词语不被包进统一卡片，避免变成后台管理界面。

### 辅助材料：语言编辑痕迹

- 校样式标注线；
- 词典词条的小型释义层；
- 来源引用的窄边栏；
- 模板槽位和派生连线。

不使用社交平台商标、真实账号头像或仿制具体 App 界面。故事讨论平台语言，但不替平台做品牌展示。

## 4. 比较框架

1. **时间轴：** 2005–2025，桌面横向、移动端纵向。
2. **证据轨道：** 年度入选 / 网络语境 / 搜索关注 / 新闻或公共表达。
3. **语义场：** 经复核的主题区域，不以固定二维坐标伪装精确距离。
4. **模板族：** 原词居中，后续变体沿有向分支展开；只有可核查关系才连线。

## 5. 视觉状态阶梯

| 状态 | 语义操作 | 保留对象 | 新编码 | 读者理解 | Stage 3 关键帧要求 |
|---|---|---|---|---|---|
| V0 | Instantiate | “YYDS” | 无 | 这是要跟随的具体词 | 单词、空屏、标题前场景 |
| V1 | Demonstrate | “YYDS” | 时间位置 | 一个词有可核查年份 | 单词落到 2021 |
| V2 | Encode | “YYDS” | 证据轨道与缺失段 | 不同来源回答不同问题 | 四轨道教学图 |
| V3 | Duplicate | 2021 同年词 | 同年并列 | 它不是孤立案例 | 同年词进入但保留高亮 |
| V4 | Align | 全部词 | 2005–2025 档案 | 二十年可以比较，但榜单系列不同 | 全景时间场 |
| V5 | Reorder | 全部词 | 生命周期类型 | 热词有不同命运 | 分类重排及“未知”组 |
| V6 | Mechanize | 有跨语域证据的词 | 迁移轨道 | 词可能离开原平台进入公共表达 | 网络—搜索—新闻迁移 |
| V7 | Mechanize | 模板词及派生词 | 槽位与分支 | 留下来的可能是结构 | 中央揭示：词拆出模板 |
| V8 | Aggregate | 全部词 | 语义领域占比/构成 | 被命名的生活领域发生变化或保持稳定 | 同口径时期比较 |
| V9 | Explore | 全部词 | 搜索、筛选、详情 | 读者检查自己记得的词 | 有默认词的探索器 |
| V10 | Return | “YYDS” | 完整上下文 | 开场判断被证据重新解释 | YYDS 回到所属词群 |

任何状态若缺少相应数据，不制作动画占位；删去或收窄该状态。

## 6. 编码规则

### 主要编码

| 属性 | 表示 | 限制 |
|---|---|---|
| 位置 | 年份、证据轨道或语义分组 | 每次重排先解释坐标意义 |
| 字重 | 当前叙事焦点或选择 | 不直接表示频率 |
| 文字不透明度 | 当前窗口内的证据可见性 | 不把褪色写成“死亡” |
| 边框/下划线 | 榜单系列、证据等级或模板槽位 | 与颜色同时使用 |
| 连线 | 已核查的变体、模板或迁移关系 | 不画推测关系 |
| 小型时间线 | 可比趋势数据 | 缺失保留断点 |

### 禁止编码

- 字号不同时表示热度、年份和编辑焦点；
- 不把榜单名次映射成词语“重要性”；
- 不让随机位置暗示语义相近；
- 不用动画速度表示无法量化的传播速度；
- 不用词语数量变化推断中文词汇总量变化。

## 7. 色彩角色

色值已在 Stage 3 桌面与移动关键帧中验证：

| 角色 | 暂定色相 | 用途 | 非颜色提示 |
|---|---|---|---|
| 基底 | `#fffaf0` / `#10131a` | 正文与开场切换 | 明暗层级 |
| 当前词 | `#d94835` | 当前叙事对象、选中词 | 粗字重 + 双下划线 |
| 网络原生 | `#1769e0` | 网络语境证据 | 左侧方括号标记 |
| 跨语域 | `#0a8f75` | 可核查的迁移状态 | 轨道位置 + 箭头 |
| 模板结构 | `#7b4fd2` | 槽位、派生与结构族 | “××”占位符 + 虚线分支 |
| 缺失/未知 | `#b8b0a4` | 无数据、不可比、尚不能判断 | 斜纹/断线 + 文字 |

色彩不得承担唯一含义；正文与交互控件按 WCAG AA 对比度校验。

## 8. 字体与排版

- 词语标记：中文无衬线，优先系统可用的苹方、思源黑体、微软雅黑等；使用可变字重时必须提供静态回退。
- 正文：清晰的中文阅读字体栈，不复制 The Pudding 的 house fonts。
- 时间、来源、证据标签：等宽或窄体风格，仅作辅助，不让页面变成代码终端。
- 标题可以使用超大单词，但开场仅保留一个主词和少量文字。
- 中文换行遵守标点挤压和禁则，窄屏避免将四字短语拆成难读的单字列。
- 所有图形注释尽量直接贴近词条；不设置需要反复对照的大图例。

## 9. 动效语法

每个动效必须回答一个问题：

| 动效 | 回答 |
|---|---|
| 弹幕进入后停住 | 一个转瞬即逝的表达怎样成为记录对象？ |
| 词条移到年份 | 它何时进入可核查档案？ |
| 同年词加入 | 它在同一时代处于什么上下文？ |
| 全部词对齐 | 个案怎样属于总体？ |
| 词条跨轨道移动 | 在哪里观察到语域迁移？ |
| 短语显出“××”槽位 | 一个具体表达怎样变成可复用结构？ |
| 词条重排到语义场 | 二十年的关注对象如何组成不同语言世界？ |

动画可中断，回滚恢复，持续时间短于读者完成一步滚动所需时间。不使用永久循环的漂浮词语。

## 10. 桌面构图方向

Stage 2 只规定构图功能，Stage 3 才呈现实际线框和关键帧。

### 开场

- 近黑空屏；
- 一条白色/电蓝“YYDS”横向进入后停住；
- 标题与副标题在词停住后出现；
- 无控制面板、无全量词云。

### 教学状态

- 左侧或中央保留大号选中词；
- 右侧逐步出现年份和证据轨道；
- 每步只新增一种编码。

### 全景与中央揭示

- sticky 词场占约 60–68% 宽度；
- 步骤文案占 28–34%，有充分留白；
- 从时间排列到生命周期、迁移和模板族时，词条保持身份；
- 中央揭示前降低页面密度，先只保留 3–5 个有证据的模板族。

### 探索器

- 全局词场保持在背景或上方；
- 搜索结果不取代总体，只高亮并打开侧栏详情；
- 策展词作为可点击文字而不是缩略图卡片墙。

### 结尾

- 回到一个词与短段正文；
- 探索器仍可在结尾之后访问，但不代替结论。

## 11. 移动端重新设计

移动端不是缩小桌面：

- 年份改为纵向，词语按可阅读行排列；
- sticky 区域位于上半屏，约 44–52 `svh`；步骤卡在下方，不遮住词；
- 选中词保持在 sticky 顶部，年份和轨道在其下；
- 全景只加载当前年份窗口和少量邻近年份，底部提供完整文字列表；
- 生命周期分类变为纵向分段，保留当前词的定位线；
- 模板族采用单列“原词 → 槽位 → 变体”展开，不画拥挤网络；
- 搜索和筛选使用可折叠底部面板，但不拦截浏览器返回手势；
- 详情页支持锚点与 URL 状态，可分享一个具体词；
- 横屏模式不强制旋转提示，自动切换为较短 sticky。

## 12. 减少动态

`prefers-reduced-motion` 下：

- 弹幕进入改为静态出现；
- 重排不播放路径，直接落到新位置；
- 跨轨道迁移使用前后并排和箭头；
- 模板拆分使用高亮槽位与静态分支；
- 每个状态的文字摘要保持一致；
- 不删除任何证据、标签或控制。

## 13. 无脚本与观察器失败

- 预渲染标题、连续正文、关键结论和按年份词表；
- 每个 scrolly 后提供可读的静态图注/HTML 摘要；
- 搜索不可用时提供按年份和拼音首字母索引；
- sticky/IntersectionObserver 失败时所有步骤按文档顺序展开；
- 数据与方法链接不依赖 JavaScript。

## 14. 无障碍

- 每个 SVG/图形状态有可读标题和一句当前结论；
- 复杂词场提供等价 HTML 列表；
- 搜索按 ARIA combobox 规范实现；
- 键盘焦点在重排后不丢失；
- 放大 200% 时不截断正文或控制；
- 词语详情中的攻击性、歧视性或创伤性内容提供上下文提示；
- 不用朗读器逐字朗读数百个不可见词；默认摘要后允许展开完整列表。

## 15. 视觉伦理边界

- 不把词语“死亡”做成墓碑、尸体或淘汰游戏；
- 不把流行语使用者按年龄标签化或嘲讽；
- 不用平台截图暴露普通用户账号；
- 不把官方榜单包装为唯一权威的中文全貌；
- 不把敏感词的高热度设计成奖牌或胜负；
- 不模仿 The Pudding 的标志、字体和品牌页面，只借鉴其具体到总体、同一对象持续重排、解释后探索的叙事方法。
