## 场景级布局与行为

### 1. 开场：`opening-yyds` / `opening-title`

- 桌面：词居中，标题延迟到词停住后出现；不显示导航、数据规模和搜索。
- 移动：词保持单行，约占视口宽度 55%；标题在下一滚动段出现。
- 动效：横向进入 420–560ms，停住后双下划线出现。
- 减少动态：首帧直接静态显示 YYDS、问题和下划线。
- 降级：无脚本时按标题、导语、静态词标顺序呈现。

### 2. 编码教学：`encoding-year` / `encoding-lanes`

- 桌面：左侧保留大号 YYDS，右侧时间轴和证据轨逐步出现。
- 移动：YYDS 固定在 sticky 顶部；时间和四轨改为纵向。
- 一步只新增一个编码：年份 → 轨道 → 线型说明。
- 斜纹表示没有可比趋势；虚线表示有线索但尚未完成验证。
- 永远不使用字号表示热度。

### 3. 档案：`cohort-2021` / `archive-overview` / `archive-method-breaks`

- 桌面：按年份分列，词语可读，YYDS 有定位线；视觉不做词云。
- 移动：一次展示当前年份与相邻年份，底部提供完整按年列表。
- 当年度条目超过可读密度时按系列分层，不缩小到低于 14px。
- 方法改变用整列分隔和短说明，不藏进 tooltip。

### 4. 生命史：`life-paths` / `life-paths-counterexample`

- 同一个词从年份列移动到分组，不销毁再创建。
- 每组显示定义、进入条件、反例和样本量。
- “尚不能判断”与其他组同等可见。
- 如果某组少于预设最低证据量，则合并为“其他已观察路径”或删除，不用空动画占位。

### 5. 跨语域：`register-migration` / `register-warning`

- 实线：已复核的两端证据；虚线：一端已核、另一端待核；点线：只有检索线索。
- 轨道移动不表示因果、价值或成功；解释卡始终可见。
- 移动端改为上下并排的前后状态与箭头，不播放长路径。
- Stage 4 未通过的线整条删除，不能保留成“示意数据”。

### 6. 中央揭示：`template-reveal` / `template-comparison`

- 先保留完整原句，再高亮可替换槽位，最后展开派生。
- 桌面最多同时展示 3–5 个模板族；移动端单列展开“原词 → 槽位 → 变体”。
- 变体必须能回到上下文、日期与来源；编辑演示句不得冒充语料实例。
- 中心文案只有在统计检验与证据审计通过后定稿。

### 7. 语义场：`semantic-fields` / `semantic-caveat`

- 词语重排到离散主题区域，不使用伪精确二维距离。
- 只比较方法一致时期、同系列有效词条占比。
- 低置信与多义词显示标签；悬停/聚焦可读官方释义与编辑理由。
- 若趋势不稳，正文改为呈现构成而不写方向性结论。

### 8. 探索与结尾：`explorer-default` / `explorer-empty` / `ending-return`

- 默认值 YYDS；策展入口包括给力、YYDS、内卷、情绪价值。
- 搜索支持规范词形、异形和拼音首字母提示，但结果以规范词条为中心。
- 筛选字段：年份、榜单系列、语义、构词方式、证据层。
- URL 保存词与筛选；焦点不因结果重排而丢失。
- 结尾收起控制，让 YYDS 回到年份、结构和证据上下文；探索器仍可在结尾后访问。

## 加载、空值、错误与降级

- 初始数据加载：显示章节标题、当前状态摘要和骨架年份，不让空白 sticky 占屏；
- 单个趋势缺失：保留词条，显示“没有可比趋势”，不画 0 线；
- 数据包失败：显示预渲染章节文本、静态关键图和完整按年列表；
- 搜索无结果：解释收录范围，给出近似词与纠错入口；
- URL 中词不存在：保留查询值，回退策展默认词并说明；
- 图形尺寸异常：切换为 HTML 表或列表；
- 键盘与朗读器：状态改变后更新简短 live summary，不逐字朗读整片词场。
