# 《从“给力”到“情绪价值”》整体叙事与视觉设计

状态：Stage 2 已确认  
日期：2026-07-28  
确认日期：2026-07-29  
项目路径：`stories/chinese-buzzwords/`

## 1. 编辑承诺

这不是一份怀旧热词表，也不是把二十年的词塞进一张词云。故事要让读者经历一个观点：流行语会退潮，但语言变化并不止于词语消失；词会跨越平台、改变语域、丢失原梗，或留下能够继续生成新表达的结构。

## 2. 核心问题与暂定论点

**问题：** 一个词成为年度流行语以后，发生了什么？

**暂定论点：** 中文流行语至少具有几种不同的生命史——事件型爆发、跨语域迁移、日常化、语义转移和模板化。二十年间真正变化的不只是“我们谈论哪些事”，还有“我们用什么结构表达态度”。

**证据纪律：**

- “官方榜单入选”与“真实使用频率”分开表达；
- “被搜索”与“被使用”分开表达；
- “新闻出现”与“口语常态化”分开表达；
- 编辑分类、自动分类和原始来源分别标注；
- 中心论点在 Stage 4 数据验证后才转为定稿。

## 3. 叙事对象、动作与比较框架

- **视觉名词：** 可辨认、可搜索、可持续追踪的中文词语或短语。
- **视觉动词：** 出现、放大、褪色、迁移、拆分、繁殖、留下。
- **稳定比较框架：** 2005–2025 年时间轴；必要时增加“网络语料—搜索—新闻/公共表达”三条证据轨道。
- **对象恒常性：** 每个词条拥有稳定 ID、文字内容和来源记录。重排时移动同一个词条，不把词变成无意义粒子。

## 4. 读者与语气

读者已经认识部分词，但不需要了解语料库或语言学。语气保持聪明、亲切和克制，可以有轻微的时代幽默，但不嘲笑某代人的表达。正文写语言和社会，不写“接下来我们展示一张图”。

### 结构先例：借方法，不仿表面

- **《From Goat to Despite》：** 借鉴“文字本身作为稳定标记”和“同一批词按不同问题重排”；不复制它的两张词表、配色或页面布局。
- **《Bears Will Be Boys》：** 借鉴主题材料在统计阶段仍然保持可辨认，以及解释结束后才开放完整搜索。
- **《This is a teenager》：** 借鉴一个具体对象从开场持续到总体、机制与结尾，不在进入总体后丢失“YYDS”。
- **《The Pour-igin of Species》：** 借鉴逐步教会复杂编码、给出有意义默认值、然后交出筛选权。

## 5. 故事弧线

### 序章：你现在还会说“YYDS”吗？

一条弹幕式“YYDS”穿过空屏，随后停住。标题出现，但暂不展示方法和全量界面。

读者首先形成自己的判断：这个词已经消失、仍然常见，还是仅仅变成了一个带年代感的标记？

### 第一章：一个词的一生

用“YYDS”教会第一个编码：

1. 首次进入本项目可核查记录的年份；
2. 它在哪些证据轨道中出现；
3. 哪些年份有数据，哪些年份没有；
4. 趋势只代表相应来源，而不是全体中文使用者。

这一步只呈现一个词，不先给数百个标签或搜索框。

### 第二章：二十年，几百个词

同年词语逐个进入，再沿年份扩展为完整档案。“YYDS”始终保留高亮。

读者先看到年度密度和词形变化，而不是立即看到类别统计。随后明确：网络用语、媒体流行语和新词语来自不同系列，不能把三类榜单名次混成同一竞争。

### 第三章：热词并不都活成同一种样子

同一批词从年份排列重组为若干待数据验证的生命周期类型：

- 事件高峰后迅速退场；
- 跨平台后进入新闻或公共表达；
- 原始出处淡去、词语日常化；
- 词义发生可记录的移动；
- 完整短语退场，但结构继续生成新句。

分类只在有证据时出现；证据不足的词进入“尚不能判断”，不强行分组。

### 第四章：词从哪里来，又走到哪里

将已有跨语域证据的词移入三条轨道：网络表达、搜索关注、新闻/公共表达。

这不是所有词都能通过的漏斗。轨道之间的移动表示可观察到的语域迁移，不表示因果，也不把新闻采用视为语言“成功”。

### 第五章：最耐活的可能不是词，而是句式

这是预设的中央揭示，但必须经 Stage 4 验证。

若数据支持，若干完整短语会拆出可复用结构，例如：

- 拼音缩写；
- 谐音替换；
- “××感”；
- “被××到”；
- “××基础，××不基础”一类留有槽位的模板；
- 对仗、递进或反差句式。

屏幕不更换为另一张图，而是让原词条保留，结构槽位从词中显现，并连接到后续变体。读者看到“词退场—结构繁殖”的机制。

若证据不支持“模板化是主要生存方式”，本章改为比较不同构词方式的出现与持续，不保留夸大的中央结论。

### 第六章：我们越来越需要为哪些事命名

词语重排到经过复核的语义领域，例如：

- 技术与平台；
- 工作、经济与消费；
- 公共事件与治理；
- 情绪、关系与自我描述；
- 娱乐、游戏与亚文化；
- 语言游戏与表达模板。

本章寻找主题结构变化，但不预设“从技术转向情绪”等方向。只有经过同口径占比和置信检查后，才写趋势句。

### 第七章：找一个你记得的词

完成“教会编码—展开全景—解释机制”后，读者获得搜索和筛选：

- 搜索词语或变体；
- 按年份、榜单系列、语义、构词方式和证据层筛选；
- 查看原始入选来源、释义、可核查上下文、生命周期证据和限制；
- 使用“给力”“YYDS”“内卷”“情绪价值”等策展入口；
- 未收录时说明范围并提供纠错/建议入口，而不是返回空白页。

### 结尾：词退场以后

回到“YYDS”。它不再孤零零地占据屏幕，而是位于自己的年份、结构和证据上下文中。

结尾不判断年轻人“更会”或“不会”说话，而是区分三件事：

1. 榜单记录了什么；
2. 语料能够追踪什么；
3. 私人交流、方言和小社群仍然留在数据之外。

最后一句的方向是：语言不只保存一个时代谈过的事，也保存人们学会怎样说这些事。

## 6. 中央揭示与现实意义

**中央揭示：** “留下来的不一定是原词，可能是一个仍在生成新表达的结构。”

**社会意义：**

- 语言记录平台形态和注意力机制；
- 流行语给新技术、劳动处境、情绪和身份经验命名；
- 一个表达进入公共语言时，可能获得传播力，也可能失去原社群语境；
- 被官方语料遗漏的语言生活提醒读者：数据本身也有边界。

## 7. 实质内容目标

成稿至少包含 5–6 个互相连接的发现或解释节点：

1. 一个具体词的可验证生命周期；
2. 年度档案的规模与方法差异；
3. 至少三种有证据的生命周期路径；
4. 至少一个跨语域迁移案例及反例；
5. 构词模板是否比单个词更持久；
6. 语义领域变化及其不确定性。

预计主动阅读 10–12 分钟；主文约 3,000–4,500 字，方法与完整词表另行展开。深度来自可验证发现，不靠延长滚动距离。

## 8. 交互策略

### 叙事阶段

- 原生滚动 + 离散 sticky scrolly；
- 每个滚动步骤只推进一个编辑判断；
- 不劫持滚轮、触摸或键盘；
- 回滚恢复上一个完整状态；
- 开场不要求输入，所有互动均可跳过。

### 探索阶段

- 默认显示经过策展的“给力”或“YYDS”，页面在不输入时仍然成立；
- 搜索使用中文模糊匹配、拼音首字母和常见异形提示，但搜索结果仍以规范词条为主；
- 所有筛选改变真实数据字段；
- URL 可保存已选词、年份和筛选状态；
- 提供重置、无结果、无趋势数据和证据不足状态。

### 不采用

- 不做需要读者不断点击才能继续的“闯关”；
- 不做词云；
- 不让词语随机漂浮形成装饰性背景；
- 不把流行语做成排行榜竞赛；
- 不把敏感或攻击性词语做成可分享的搞笑卡片。

## 9. 数据与方法计划

### 数据包

| 文件 | 内容 |
|---|---|
| `data/terms.csv` | 稳定 ID、词形、标准化词形、年份、榜单系列、原始名次/是否有名次 |
| `data/sources.csv` | 每条入选记录的一手来源、发布日期、方法说明、检索日期 |
| `data/contexts.csv` | 可复核语境、语域、时间、出处与授权状态 |
| `data/signals.csv` | 可比的年/月级搜索或语料信号，含缺失原因 |
| `data/annotations.csv` | 语义领域、构词方式、来源场景、模板族、编码者与置信度 |
| `data/variants.csv` | 异形、缩写、谐音、派生词与模板关系 |

### 方法一致性

- 先按榜单系列分别建表，再决定哪些年份可比较；
- 任何占比使用各年同系列有效词条数作分母；
- 同词异形通过规范字段连接，但保留原始写法；
- 多义词按入选年份的官方释义和语境编码；
- 自动语义标签只作初筛，最终类别需人工复核；
- 模板族必须保留可核查的至少两个派生实例和时间关系；
- 若无法合法、稳定地取得原始趋势，不显示伪精确生命周期曲线。

### 证据标签

每个词条的详情明确标出：

- `年度入选`：有一手榜单；
- `语境证据`：有可复核使用实例；
- `跨语域证据`：在另一语域中可观察；
- `趋势证据`：有可比的时间序列；
- `编辑分类`：本项目的语义或结构编码。

## 10. 不确定性呈现

- 缺失年份保留空段和文字说明，不用插值补线；
- 榜单方法变化在年份分隔处直接标注；
- 没有趋势证据的词仍可进入档案，但不进入寿命统计；
- 置信度不用单一颜色表示，同时用标签、线型和文字；
- 主文中的每个总体结论都链接到相应方法和词条集合；
- 反例与无法归类词不会被藏进脚注。

## 11. 移动端、无障碍与降级计划

- 移动端把时间轴改为纵向；选中词固定在图形顶部，而不是把桌面横轴压缩；
- sticky 图形控制在约 44–52 `svh`，正文卡片在其下自然滚动；
- 数百词全景改为按年份窗口或聚焦词群逐步载入，仍保留“查看完整列表”；
- 文字标记使用真实 DOM/SVG 文本，支持选择、缩放和辅助技术；
- 搜索、筛选与词条详情均可键盘操作，触控目标不少于 44 CSS px；
- 颜色之外使用边框、下划线、轨道位置和明确文字标签；
- 图形提供短标题、当前状态摘要和等价 HTML 列表；
- JavaScript、IntersectionObserver 或 sticky 失败时，显示按章节预渲染的静态状态和完整正文；
- `prefers-reduced-motion` 下直接切换位置与标签，不播放迁移、拆分或扩散动画。

## 12. 技术方案

新故事采用当前 Pudding website starter 与 DataSlices 最新故事一致的技术基线：

- Svelte `5.1.3`，runes 模式；
- SvelteKit `2.7.3`；
- `@sveltejs/adapter-static` `3.0.6`；
- Vite `5.4.10`；
- D3 `7.9.0` 用于比例尺、文字布局与过渡目标计算；
- route-level prerender；
- GitHub Pages base path `/dataslices/stories/chinese-buzzwords`；
- `trailingSlash = "always"`，验证子路径刷新；
- Node `>=18.20.4`，CI 使用 Node 20。

### 状态边界

- `src/lib/state/story.svelte.js`
  - `$state`：当前 authored step、用户搜索、筛选、选中词、减少动态偏好；
  - `$derived`：完整可视状态、可见词集合、布局目标、标签、图形摘要；
  - `$effect`：只用于 URL、焦点和外部观察器同步。
- `Scrolly.svelte`
  - IntersectionObserver 只写入离散步骤；
  - 不直接批量修改 SVG。
- 数据预处理脚本
  - 生成规范化 JSON/CSV、布局缓存、搜索索引和静态摘要；
  - 浏览器不承担语义分类或重型分词。

### 组件边界

## 14. Stage 2 验收标准

- 论点不是“二十年热词盘点”；
- 同一个词条从开场持续到总体数据与结尾；
- 第一种编码通过一个具体词教会；
- 至少 5 个实质发现位置已被叙事结构预留；
- 中央揭示可以被数据否证并有收窄方案；
- 探索器晚于解释出现；
- 移动端、减少动态、无脚本路径均有独立设计；
- 技术方案完全采用 Svelte 5 / SvelteKit 静态预渲染 / runes 状态层 / sticky scrolly；
- 仓库继续保持一故事一目录，不破坏现有 DataSlices。
