# 《消失的星空》视觉系统 v2

> 配套文档：`04-overall-design-v2.md`
> 文档性质：总体设计阶段视觉语言、状态和适配规范
> 状态：总体设计已于 2026-07-28 确认；详细关键帧见 v3 设计板
> 日期：2026-07-28

## 1. 视觉概念

新版视觉世界不是“深色背景上的科技图表”，而是：

> **一册会被城市灯光逐页擦除的观星图谱。**

图谱提供星的位置、名称和亮度；城市辉光提供一条移动的可见边界。故事中的地图、时间和照明光路都从这两种材料生长出来。

主视觉材料：

- 真实恒星点位；
- 星图细线与坐标刻度；
- 可见阈值；
- 城市天空辉光；
- 照明光路。

辅助材料：

- 地理轮廓与城市距离剖面；
- 观测、模型、估计和情景标签；
- 直接贴近恒星的短注释。

不得使用：

- 随机星空粒子；
- 3D 地球；
- 发光卡片矩阵；
- 霓虹赛博朋克城市；
- 与数据无关的银河照片；
- 仪表盘式综合指数；
- Pudding 的品牌字体、标志或版式复制。

## 2. 视觉名词与视觉动词

### 视觉名词

同一批真实恒星。

每颗恒星在所有状态中保持：

- `star_id`；
- 天空坐标；
- 视星等；
- 名称或目录编号；
- 证据来源；
- 当前可见状态。

### 视觉动词

跨过。

阈值跨过恒星，恒星跨过肉眼边界。动效语义只包含：

- 出现；
- 对齐；
- 标注；
- 聚合；
- 跨线；
- 失去对比；
- 返回坐标。

## 3. 视觉状态语法

| 操作 | 画面变化 | 语义 |
|---|---|---|
| 实例化 | 城市猎户座出现 | 认识真实对象 |
| 预测 | 只标亮星骨架 | 让读者形成“星座仍完整”的预期 |
| 揭示 | 较暗星在原坐标返回 | 显示缺失 |
| 隔离 | 选出一亮一暗两颗星 | 教会可见差异 |
| 对齐 | 星从天空移动到星等轴 | 建立可比较尺度 |
| 编码 | 位置表示视星等，实心/空心表示可见状态 | 教会图形语法 |
| 复制 | 更多真实恒星加入 | 从例子扩展到天区 |
| 聚合 | 累计星数曲线出现 | 让非线性结构显形 |
| 跨线 | 阈值移动，星逐颗变为空心 | 显示损失发生 |
| 时间化 | 年龄推进，阈值持续移动 | 解释代际尺度 |
| 地理化 | 地点改变阈值，同一星空保持 | 解释空间差异 |
| 机制化 | 背景辉光拆成地面光路 | 解释因果路径 |
| 测试 | A/B 灯具改变光路 | 展示可干预部分 |
| 返回 | 所有星回到开场坐标 | 完成叙事回环 |

每次滚动只承担一个操作。不得同时移动坐标、改变颜色、切换地点和添加新指标。

## 4. 第一编码如何被教会

### 第一步：不出现数字

只显示两颗真实恒星。较亮星清楚可见，较暗星接近背景。

文字：

> 两颗星都在。城市先拿走的，是较暗那颗与背景之间的差别。

### 第二步：引入亮—暗顺序

两颗星移动到一条“更亮 → 更暗”的简化轨道。

### 第三步：引入视星等

轨道增加 0、2、4、6 刻度，并直接标注：

> 数字越小，星越亮。

不在第一次出现时解释对数定义或波段细节。

### 第四步：引入阈值

阈值从暗端进入。越过阈值的星变为空心位置环，而不是完全消失，让读者知道星仍然存在。

### 第五步：扩展到完整天区

更多星沿同一轴加入，亮星保持高亮，开场较暗星保持标注。此后才出现累计曲线。

## 5. 恒星标记

### 可见恒星

- 实心圆；
- 半径由视星等映射，但设置最小与最大值；
- 亮星可有短十字芒，仅用于肉眼辨认，不使用循环闪烁；
- 颜色由有限色温组映射，分析上不承担可见状态。

### 不可见恒星

- 在星等轴和教学状态中保留细空心环；
- 在自然星空状态中可完全退出视觉，但屏幕阅读文本保留数量与例子；
- 被选中的追踪星始终保留位置环。

### 估计边界附近

- 使用双环或轻微虚线环；
- 不使用模糊闪烁；
- tooltip/注释写明“可能可见，取决于条件”。

### 星座线

- 仅作为识别辅助；
- 在亮星骨架状态之后出现；
- 线宽低于阈值线；
- 不进入统计图状态。

## 6. 可见阈值

阈值是全文最重要的非恒星标记。

### 在星等轴上

- 垂直或水平实线；
- 旁边直接写“当前可见边界”；
- 模型/估计状态使用带宽而不是单线；
- 情景状态使用虚线。

### 在星空中

阈值不画成遮罩墙。它通过：

- 背景辉光；
- 星体实心/空心状态；
- 当前边界注释；
- 可见星数区间

共同表达。

### 在城市路线中

地图点位不使用“好/坏”颜色排名。每个地点连接到：

- 天空亮度模型区间；
- 推导阈值区间；
- 观测覆盖；
- 固定星空状态。

## 7. 色彩系统

### 基础色

| 角色 | 暂定色值 | 用途 |
|---|---|---|
| 深夜底色 | `#070910` | 星图与主要深色章节 |
| 图谱纸色 | `#F0EBDD` | 方法、长文与明亮转场 |
| 主文字暖白 | `#F5F0E6` | 深色背景正文 |
| 深色文字 | `#191B21` | 明亮背景正文 |
| 次级文字 | `#9DA6B5` | 说明、坐标与未激活状态 |

### 分析色

| 角色 | 暂定色值 | 规则 |
|---|---|---|
| 城市辉光 | `#D38B4A` | 只表示人工天空背景或上射光 |
| 阈值 | `#F1C56A` | 只表示当前可见边界 |
| 观测 | `#83C5D5` | 公众/卫星观测标签 |
| 模型 | `#9B8FC8` | 模型值及网纹 |
| 估计 | `#D2A7C7` | 区间带 |
| 情景 | `#B9AFA0` | 虚线边界和情景标签 |

恒星本身以暖白、冷白和低饱和浅黄为主，不使用分析色填充，以免把物理颜色与证据类型混淆。

### 非颜色编码

- 观测：实心；
- 模型：细网纹；
- 估计：半透明区间带；
- 情景：虚线；
- 不可见：空心环；
- 选中：双环和文字标签。

## 8. 字体与文字层级

### 字体方向

- 主标题：高对比中文宋体或具有天文年鉴气质的衬线字体；
- 章节标题：同一衬线体系；
- 正文、坐标、控件：中性中文无衬线；
- 数字：使用等宽或表格数字特性，避免阈值移动时宽度跳动。

正式字体在实现前验证：

- 中文字符覆盖；
- GitHub Pages 加载体积；
- iOS Safari 字重；
- 320px 断行；
- 本地字体回退。

不复制 Pudding 的品牌字体。

### 层级

- H1：桌面 88—150px；手机 52—72px；
- H2：桌面 46—72px；手机 34—46px；
- 正文：桌面 18—20px；手机 17—19px；
- 数据注释：桌面不小于 14px；手机不小于 13px；
- 控件：不小于 16px；
- 行宽：中文正文约 28—34 个汉字。

## 9. 构图节奏

### 开场

- 大面积负空间；
- 星星先于标题被看见；
- 视觉焦点不超过 3 个；
- 不出现卡片和控制台。

### 教学

- 画面密度逐步增加；
- 每一步只新增一个标记或编码；
- 注释贴近星体；
- 图例在编码已经被教会后才出现。

### 中央揭示

- 恒星密度最高；
- 阈值与累计曲线同时出现，但只有一个主动注释；
- 揭示后留出一个纯文字短段落，让读者消化。

### 城市路线

- 地图与星空共享一个当前地点标签；
- 地图不占满视口；
- 选中点位突出，其余路线仍保留上下文。

### 结尾

- 退出统计坐标；
- 回到星图空间；
- 控件减少；
- 方法入口与正文之间留出明显节奏差。

## 10. 动效规则

### 允许

- 同一恒星从天空坐标移动到星等轴；
- 阈值短距离移动；
- 实心标记变为空心；
- 地点切换时背景和阈值更新；
- 光路在 A/B 状态间改变；
- 向上滚动精确恢复。

### 禁止

- 恒星随机飞散；
- 连续闪烁；
- 银河循环流动；
- 自动播放一整代人的 18 年；
- 地图在城市间飞行；
- 光束为气氛无限循环；
- 用 fade 替代所有语义过渡；
- unrelated chart morphing。

### 时间

- 普通状态转换：250—450ms；
- 重要对齐转换：500—800ms；
- 不使用超过 1.2 秒且不可跳过的动画；
- 连续阈值由滚动或控件直接控制；
- 动画可中断。

## 11. 桌面布局原则

### Hero

- 星图 100vw × 100svh；
- 文字占左下或右下不超过 38%；
- 关键恒星避开标题安全区；
- 滚动提示不使用持续弹跳。

### Threshold scrolly

- sticky 图形约 62—68vw；
- 步骤约 28—32vw；
- 图形内部包含星图、星等轴和当前注释，不出现分离图例栏；
- 步骤卡不使用统一白色矩形盒。

### Generation scrolly

- 同一星图和阈值保留；
- 年龄和可见数量成为辅助层；
- 不制作四张并列天空截图。

### City transect

- 地图/距离剖面约 42%；
- 固定星空约 50%；
- 中间保留 8% 呼吸空间；
- 证据年份和区间紧贴当前点位。

### Light path

- 星体位于上方结果层；
- 大气位于中层；
- 灯具和地表位于下层；
- 卫星和人眼是观察方向，不做独立卡片。

## 12. 手机布局原则

### 320—430px

- 使用单列阅读；
- 星图 sticky 高度 58—64svh；
- 文字步骤在星图下方，不以半透明卡覆盖关键星体；
- 当前步骤标题固定在星图下缘安全区；
- 星等轴改为纵向亮度梯；
- 追踪星标签最多保留 2 个；
- 地点路线用横向节点与距离信息，完整地图按需展开；
- A/B 光路上下排列；
- 方法表允许横向滚动，但主要结论先以列表表达。

### 横屏手机

- 取消过高 sticky；
- 星图与文字可短暂并列；
- 控件不进入安全区或浏览器工具栏区域。

### 平板

- 768px 时允许 45/55 双栏；
- 不直接套用宽桌面字号；
- 星图触控区域保持 44px。

## 13. 减少动态与回退

### `prefers-reduced-motion`

- 不执行星体连续轨迹；
- 直接切换“天空坐标 / 星等轴”两种状态；
- 阈值按离散位置跳转；
- 18 年显示 0、6、12、18 四个按钮和并列结论；
- 城市路线显示五个地点按钮；
- A/B 光路静态并排；
- 所有结论和数值不减少。

### Observer 失败

- scrolly 退化为按顺序排列的图文关键帧；
- 当前状态不依赖滚动监听才能阅读；
- 图形每帧有标题和一句结论。

### JavaScript 失败

- 预生成 PNG/SVG 关键帧；
- 显示开场城市天空、较暗天空、星等分布、18 年四状态、地点比较和 A/B 光路；
- 提供恒星数据与地点数据表；
- 正文与方法保持完整。

## 14. 无障碍视觉规范

- Canvas 提供可读名称和当前状态摘要；
- 主要状态同步输出到可读文本区域；
- 交互式恒星不依赖 2px 小点作为点击目标，使用 44px 隐形命中区；
- 所有控件有可见焦点；
- 可见/不可见不只靠透明度；
- 证据类型不只靠颜色；
- 阈值带保持足够对比；
- 明亮纸色章节文字达到 WCAG AA；
- 星图标签避免覆盖；
- 数据表提供排序后的等价信息。
