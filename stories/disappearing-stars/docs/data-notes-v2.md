# 《消失的星空》数据说明 v2

> 状态：第四阶段内容与证据已确认

## 数据包

| 文件 | 行／对象规模 | 角色 | 可否作为读者事实 |
|---|---:|---|---|
| `data/v2/stars-orion-field.json` | 250 颗目录星 | 全文固定恒星身份 | 星位、视星等、目录属性可以 |
| `data/v2/threshold-model.json` | 4 个批准阈值 | 跨场景可见规则 | 只作为视觉编码 |
| `data/v2/generation-scenario.json` | 4 个年龄节点 | 18 年情景 | 0/18 端点与年率可以；中间计数不可以 |
| `data/v2/nyc-places.json` | 5 个点位 | 纽约空间路线 | Atlas 分档可以；不是现场预测 |
| `data/v2/lighting-presets.json` | 5 个照明预设 | 光路 A/B | 类别原则可以；不得定量恢复星数 |
| `data/v2/evidence.json` | 11 条主张 | 页面标签与方法追溯 | 依据各条证据类型 |

## 生成链

```text
Bright Star Catalogue
  → 固定宽度解析
  → 矩形天区与 Vmag 筛选
  → 250 颗稳定 star_id
  → 阈值状态与 18 年视觉映射

World Atlas KMZ
  → KML 定位瓦片
  → 经纬度映射像素
  → 论文色带分类
  → 点位亮度档
  → Kyba 北美方程推导 NELM 区间
```

## 已通过的完整性检查

- 星表条目数为 250；
- `star_id` 唯一；
- 八颗猎户座锚点都有名称与视星等；
- `Vmag <= 6.50` 和 `Vmag <= 5.48` 分别为 250 和 100 条；
- 18 年中心亮度倍数为 5.2070；
- 时代广场与中央公园同为 `>41` 档；
- 五个点位都有来源像素、分档、年份、分辨率和限制；
- 本地观测覆盖字段显式为 `null`，没有用零伪装缺失；
- 照明预设全部禁止定量输出。

## 已知限制

- BSC 是亮星目录，不适合表现望远镜深空星场；
- 矩形选区不是猎户座成员表，也不是整片可见天空；
- World Atlas 主要反映约 2014 年基线，不代表 2026 年实况；
- KMZ 是带 JPEG 压缩的分档显示产品；
- 海岸、道路和局部灯具会在像素内混合；
- Kyba 北美拟合残差约 1.009 星等；
- 没有局部 Globe at Night 校验；
- 没有灯具级辐射传输模型。

## 生产消费规则

- 组件只读取 `data/v2/`；
- 星体跨场景必须用 `star_id` 保持对象恒常；
- `illustrative_visible_count` 不进入面向读者的 6／12 岁数字标签；
- 点位 UI 必须同时显示 `evidence_type` 和 `model_year`；
- `nearby_observation_count=null` 显示为“本版未使用局部观测”，不能显示为 0；
- 所有降级模式仍保留方法限定。
