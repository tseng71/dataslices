# 《消失的星空》交互与状态规范 v1

> 配套文档：`05-storyboard-wireframes-v3.md`
> 状态：详细设计已确认；数据字段已由第四阶段 v2 数据包落地
> 日期：2026-07-28

## 1. 状态模型

生产实现必须由规范化数据派生状态，不能让组件分别计算自己的故事版本。

```text
star catalogue
  + sky/background state
  + place/model state
  + story step
  + reader control
  + motion preference
  = rendered story state
```

### 顶层状态

| 状态 | 类型 | 默认值 | 来源 |
|---|---|---|---|
| `storyStep` | 离散整数 | 0 | Scrolly |
| `selectedPlace` | 点位 ID | `times-square` 或最终首点 | 作者路径 / 控件 |
| `selectedLightingPreset` | 枚举 | `unshielded` | 作者路径 / 控件 |
| `motionMode` | `full/reduced/static` | 系统偏好 | 媒体查询 / 回退 |
| `dataStatus` | `loading/ready/partial/error` | `loading` | 数据层 |
| `observerStatus` | `ready/fallback` | `ready` | 运行时 |

### 派生状态

| 状态 | 由什么派生 | 不能在哪里重新计算 |
|---|---|---|
| 当前可见恒星 | 星表 + 阈值区间 | Canvas 组件 |
| 可见数量区间 | 当前可见恒星 + 不确定性 | 文案组件 |
| 当前星等轴位置 | 星表视星等 | Scrolly |
| 当前地点阈值 | 点位模型 + 转换模型 | 地图组件 |
| 证据类型 | 数据行 metadata | 视觉组件 |
| 当前光路 | 灯具预设 + 配光/原则数据 | 控件组件 |

## 2. Scroll 状态

### 离散步骤

- Hero、阈值教学、18 年情景和光路机制使用离散步骤；
- IntersectionObserver 选择可见比例最高的步骤；
- 步骤退出时恢复前一稳定状态；
- 快速滚动可直接跳到目标状态；
- 中间动画可被新状态打断。

### 连续进度

只允许用于：

- Hero 中天空背景的短距离连续变化；
- 中央揭示中阈值在两个已标定状态之间移动；
- 地点路线的距离剖面仅在真实连续数据存在时使用。

连续进度不得用于：

- 0—18 岁插值；
- 缺测地点；
- 从全球趋势推演某城市；
- 灯具治理综合分数。

## 3. Hero 状态

| 状态 | 星体 | 背景 | 标注 | 文案 |
|---|---|---|---|---|
| `city` | 城市阈值内实心 | 较亮 | 腰带三星 | 这是完整猎户座吗？ |
| `skeleton` | 同上 | 同上 | 5 个亮星标签 | 熟悉骨架仍在 |
| `dark-return` | 更多星实心 | 较暗 | 追踪星进入 | 原来空着的位置重新出现 |
| `constellation` | 全部批准星体 | 较暗 | 星座线 | 先前看到的只是骨架 |

减少动态：四个状态用滚动步骤直接替换，不插值。

## 4. 阈值 scrolly

| 步骤 | 布局 | 阈值 | 星体状态 | 当前注释 |
|---:|---|---|---|---|
| 0 | 天空 | 无 | 追踪星双环 | 记住这颗星 |
| 1 | 两颗星 | 无 | 亮/暗各一 | 两颗都在 |
| 2 | 简化轨道 | 无 | 两颗对齐 | 更亮 → 更暗 |
| 3 | 星等轴 | 无 | 两颗带数值 | 数字越小越亮 |
| 4 | 星等轴 | 单线/区间 | 追踪星空心 | 当前可见边界 |
| 5 | 星等轴 | 保持 | 天区星群加入 | 较暗端更密 |
| 6 | 分布 | 保持 | 累计曲线出现 | 暗星数量迅速增加 |
| 7 | 分布 | 移动 | 一批星变空心 | 边界只移动一点 |
| 8 | 天空 | 新阈值 | 城市星空 | 亮星留下，密度消失 |

## 5. 18 年情景

### 允许状态

只显示第四阶段数据包批准的年龄节点。默认设计节点：

- 0；
- 6；
- 12；
- 18。

### 约束

- 不对任意年龄输出伪精确星数；
- 星数使用论文情景的复算值和区间；
- 年龄节点之间不连续动画；
- 每个状态显示“全球平均情景”；
- 可见星状态由同一星表与阈值函数派生。

### 控件

- 桌面端由滚动驱动，节点按钮作为补充；
- 手机端滚动与按钮并存；
- 当前按钮 `aria-pressed=true`；
- 左右方向键移动相邻节点；
- Home/End 跳至首末节点。

## 6. 城市地点探索

### 默认

- 作者路径先按批准点位顺序推进；
- 探索默认停留在较暗参照地；
- “重置路线”返回首点并恢复作者说明。

### 点位数据

每个点位必须包含：

```text
place_id
display_name
longitude
latitude
model_value
model_unit
model_year
model_resolution
model_uncertainty
nearby_observation_count
observation_window
derived_threshold_interval
evidence_type
caveat
```

字段不完整时：

- 可显示真实点位；
- 缺失数据标为 unavailable；
- 不用旧版硬编码数值填补。

### URL 状态

允许：

```text
?place=central-park
```

不保存：

- 连续滚动进度；
- hover 状态；
- 设备相关布局。

### 键盘

- Tab 进入点位组；
- 左右方向键移动；
- Enter/Space 选择；
- Esc 关闭展开地图；
- 焦点不因星空重绘丢失。

### 触控

- 节点至少 44×44px；
- 横向滚动不劫持页面纵向滚动；
- 选中后点位自动进入可见范围；
- 不依赖 hover。

## 7. 照明 A/B

### 预设

| 预设 | 方向 | 亮度 | 时段 | 光谱 |
|---|---|---|---|---|
| `unshielded` | 存在上射 | 参考值 | 全夜 | 参考光谱 |
| `shielded` | 完全遮罩 | 同一地面任务 | 全夜 | 参考光谱 |
| `right-sized` | 完全遮罩 | 不高于任务需要 | 全夜 | 参考光谱 |
| `timed` | 完全遮罩 | 任务需要 | 深夜调暗 | 参考光谱 |
| `warmer` | 完全遮罩 | 任务需要 | 深夜调暗 | 较低短波成分 |

### 输出

必须显示：

- 地面任务区；
- 直接上射路径；
- 反射路径；
- 散射路径；
- 当前改变的工程维度；
- 证据来源。

只有存在批准的配光/辐射传输模型时才显示：

- 相对上射通量；
- 天空背景变化区间；
- 阈值变化区间。

永不显示：

- 任意综合分；
- “环保百分比”；
- 无来源的恢复星数；
- 成就、奖励或游戏反馈。

## 8. Tooltip 与详情

必要结论不得只放在 tooltip。

### 恒星详情

可显示：

- 名称；
- 目录 ID；
- 视星等；
- 颜色指数；
- 当前状态；
- 当前阈值区间；
- 星表来源。

### 点位详情

可显示：

- 模型值和单位；
- 年份与分辨率；
- 附近公众观测数量；
- 推导阈值区间；
- 限制。

### 行为

- hover、focus、tap 均可打开；
- Esc 关闭；
- 焦点离开后关闭；
- 手机端使用底部详情层；
- 不允许详情层遮挡关闭控件。

## 9. 加载状态

### `loading`

- 显示预生成首屏；
- 不显示骨架屏闪烁；
- 正文可立即阅读；
- 控件禁用并写“数据正在加载”。

### `ready`

- 用真实数据替换首屏；
- 视觉差异不得造成布局跳动；
- 控件启用。

### `partial`

- 可用模块继续；
- 缺失模块显示静态表或说明；
- 不阻止全文阅读。

### `error`

- 使用静态关键帧；
- 方法入口可用；
- 错误信息面向读者，不暴露技术堆栈。

## 10. Reduced motion

`motionMode=reduced` 时：

- 所有星体位置切换直接完成；
- 阈值使用离散前后状态；
- 不自动滚动或平滑滚动；
- 不显示循环光束；
- 地点切换不缩放地图；
- A/B 直接替换；
- 当前状态文本同步更新；
- 所有事实与限制完整保留。

## 11. Static / no-observer

`motionMode=static` 或 `observerStatus=fallback` 时：

- scrolly 步骤按文档顺序展开；
- 每个步骤配一张预生成关键帧；
- 图形标题包含当前状态；
- 所有图下有一句结论；
- 当前阈值、可见数量和证据类型进入表格；
- 地点探索变为按钮和静态星图；
- A/B 变为上下两图。

## 12. 空状态

| 情况 | 显示 | 不显示 |
|---|---|---|
| 点位无模型值 | 地点、无数据说明 | 合成阈值 |
| 点位无公众观测 | 模型值、覆盖不足 | “已验证”标签 |
| 星表无中文名 | 目录 ID | 编造中文名 |
| 阈值公式不适用 | 背景亮度区间 | 可见星数 |
| 生态证据未通过 | 无该章节 | 通用动画 |
| 配光数据不足 | 原则示意 | 通量比例 |

## 13. 状态验收

- [ ] 快速滚动不会留下中间状态；
- [ ] 向上滚动恢复同一星 ID 和阈值；
- [ ] 旋转屏幕后当前地点和年龄保持；
- [ ] 浏览器返回键恢复 URL 点位；
- [ ] 减少动态不减少步骤；
- [ ] 数据加载失败不生成模拟替代值；
- [ ] 键盘焦点不因 Canvas 重绘丢失；
- [ ] 手机横向点位滚动不阻止纵向页面滚动；
- [ ] A/B 改变同一任务区域，不偷换照明目标；
- [ ] 静态回退按叙事顺序完整可读。
