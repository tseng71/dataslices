## 无障碍

- 正文顺序不依赖 JavaScript 互动；
- 所有按钮最小高度 44px，并使用 `aria-pressed`；
- 键盘可切换年龄节点，支持方向键、Home 与 End；
- 图形有可读名称、状态摘要和数据属性；
- 可见 / 不可见同时使用实心 / 空心，而不只使用颜色；
- `prefers-reduced-motion` 下关闭平滑滚动和长动画；
- 焦点样式使用高对比阈值黄。

## 性能

- 主要脚本压缩前约 101 kB；
- 四个完整中文字库 woff2 合计约 5.4 MB，是当前主要负载；
- 250 个 SVG 星体在目标设备规模内可接受，换取稳定 ID、无障碍与确定性测试；
- 第六阶段发布前可在不改变视觉的前提下按最终正文字符重新生成字体子集。

## 已知限制

- World Atlas 地点值是区域模型分档，本版没有局部 Globe at Night 观测验证；
- 地点阈值只是一把模型区间尺，不是某晚、某人的可见星数预报；
- 6 岁与 12 岁节点不对读者宣称精确可见星数；
- 照明比较没有完整配光与大气传输模型，因此不输出定量恢复；
- 第五阶段不修改线上旧版 URL，不执行 GitHub Pages 部署。
