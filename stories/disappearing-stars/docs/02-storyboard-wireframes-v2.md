## 场景 01：Hero——星星没有消失

### 叙事任务

在读者尚未接触任何指标前，先通过滚动经历一次夜空被城市光逐渐洗白。

### 屏幕结构

```text
┌───────────────────────────────────────┐
│ DataSlices / 数据切片                 │
│                                       │
│              真实星空 Canvas          │
│                                       │
│  一个关于光、记忆与夜晚的故事          │
│                                       │
│  消失的星空                           │
│  一代人失去了多少颗星？                │
│                                       │
│  如果你长期住在大城市，                │
│  你可能从未真正见过银河。               │
│                                       │
│                 ↓ 向下滚动             │
└───────────────────────────────────────┘
```

### 滚动状态

- 0%：可见极限约 6.2 等，银河背景轻微可见；
- 25%：天空背景开始变灰，6 等左右暗星消失；
- 50%：银河淡出，5 等星明显减少；
- 75%：城市光穹从地平线升高；
- 100%：只保留约 3 等以上亮星。

### 视觉规则

- 恒星位置固定；
- 暗星按视星等从暗到亮依次失去对比；
- 不使用随机闪烁作为主要变化；
- 城市光穹为暖琥珀色，天空上部保持灰蓝；
- 标题在滚动前半段保持清楚，后半段逐渐让位给画面。

### 关键文案

> 如果你长期住在大城市，你可能从未真正见过银河。

章节退出句：

> 星星没有消失。消失的，是夜晚。

### 数据性质

- 星的位置和亮度：正式版使用真实星表；
- 光穹变化：机制驱动的视觉模拟，不是具体城市实测。

## 场景 02：全球尺度——很多人从未见过

### 叙事任务

从个人感受切换到全球范围，说明这不是少数大城市居民的特殊体验。

### 布局

正文窄栏，中间插入跨栏大数字：

```text
正文段落

┌───────────────────────────────────────┐
│  超过 80%                             │
│  的世界人口生活在人造光影响的夜空下。   │
└───────────────────────────────────────┘

正文段落
```

### 文案顺序

1. 城市夜空看起来正常，是因为人们已经适应；
2. 暗夜中的星空具有密度、层次和银河结构；
3. 2016 世界人工夜空亮度图的全球估计；
4. “很多人不是很久没见过，而是从未见过”。

### 视觉

数字不使用仪表盘或饼图。以大字号、边界线和大量留白建立重量。

## 场景 03：代际情景——250颗星怎样变成100颗

### 叙事任务

把年均天空辉光变化转化为人的成长时间，让读者感受“每年看不出，但18年足以改变夜空”。

### 桌面布局

```text
┌──────────────────────┬──────────────────────┐
│                      │  文字步骤 1           │
│  固定星空             │                      │
│                      │  文字步骤 2           │
│       0 岁            │                      │
│                      │  文字步骤 3           │
│  约 250 颗可见星      │                      │
│                      │  文字步骤 4           │
└──────────────────────┴──────────────────────┘
```

左侧可视化 sticky，右侧四个滚动步骤：0、6、12、18 岁。

移动端：星空固定在顶部约 65—70vh，文字步骤覆盖下部渐变区域。

### 状态表

| 年龄 | 星数显示 | 画面表达 | 文案任务 |
|---:|---:|---|---|
| 0 | 约250 | 暗星丰富 | 建立初始情景 |
| 6 | 约200 | 最暗星减少 | 一年变化难记忆 |
| 12 | 约145 | 星座间结构断裂 | 熟悉星座仍在，误以为没变 |
| 18 | 约100 | 光穹明显 | 完成代际尺度 |

星数是叙事情景值。画面不必精确做到每个年龄星数完全等于显示数字，但正式版应使用统一函数和星等阈值，使显示和图像逻辑一致。

### 关键句

> 这种变化不是一夜发生的。它慢到足以骗过记忆，却快到足以改变一代人的夜晚。

### 口径说明

紧贴第18岁步骤显示：

> 按研究中的全球平均天空辉光增长情景推演；不是对纽约、深圳或任何具体地点的精确预测。

### 叙事任务

### 控件范围

- 2.0—6.5 等；
- 步长 0.1；
- 手机端滑杆全宽；
- 键盘可操作。

## 场景 05：物理机制——地面如何点亮天空

### 叙事任务

解释光污染不是“天上多了一层灯”，而是地面灯光方向、反射和大气散射共同抬高天空背景。

### 页面结构

正文—剖面图—正文的三段结构，作为高互动章节后的安静解释段。

### 剖面图层级

```text
高空：暗星逐渐变淡
────────────────────────
大气：分子、水汽、颗粒
      ↗  ↖  散射光
   ╱      ╲
地面：路灯 / 建筑 / 广告牌 / 停车场
────────────────────────
```

### 动画顺序

1. 地面灯具亮起；
2. 一部分光直接向上；
3. 一部分光落地后反射；
4. 大气中出现散射；
5. 城市上方形成光穹；
6. 背景变亮，暗星淡出。

### 重要解释

卫星从上方测量离开地面的辐亮度；人在地面看到的是经过方向、光谱、大气和周边城市共同影响后的天空。二者相关，但不能直接画等号。

## 场景 06：地点—星空联动——从时代广场到更暗地点

### 叙事任务

把抽象光污染地图转译为“同一片星空在不同地点还剩什么”。

### 桌面布局

```text
┌───────────────────────┬───────────────────────┐
│ 纽约区域地图            │ 同一天区星空            │
│                        │                       │
│ ●时代广场               │                       │
│ ●中央公园               │ 地点名称                │
│ ●牙买加湾               │ 可见极限区间            │
│ ●佩勒姆湾               │ 银河状态                │
│ ●更暗参照地             │ 说明与不确定性           │
└───────────────────────┴───────────────────────┘
```

### 手机布局

1. 当前地点星空；
2. 地点名称和说明；
3. 地图；
4. 横向可滚动地点按钮。

### 互动

- 点击地点更新星空；
- 桌面端 hover 可预览，但点击才固定；
- 键盘 Tab 可到达每个地点；
- 地图选中点与星空标题同步；
- 提供“这不是实时天气”的说明。

### 地点

- 时代广场；
- 中央公园；
- 牙买加湾；
- 佩勒姆湾公园；
- 都市圈外更暗地点。

最后一项标题必须写“更暗参照地”或“从城市中心到更暗的夜晚”，不能误称所有点都位于纽约市内。

### 正式数据要求

- 使用真实地理边界与地点坐标；
- 以人工天空亮度模型为基础；
- Globe at Night 数据足够时做局部校验；
- 以区间表达极限星等；
- 明确数据年份；
- NASA Black Marble 只用于地面夜光变化辅助，不直接输出可见星数。

## 场景 07：两把尺子——卫星和人眼测量的不是同一件事

### 叙事任务

主动解释数据差异，避免读者把所有夜光数据理解为同一个指标。

### 布局

```text
┌─────────────────┐   ≠   ┌─────────────────┐
│ 卫星从上往下看   │       │ 人从下往上看     │
│ 地面辐亮度       │       │ 肉眼可见极限     │
│ 道路和开发变化   │       │ 实际星空体验     │
└─────────────────┘       └─────────────────┘
```

### 核心句

> 卫星测量从地面离开的光。  
> 人眼测量最终留在天空中的星。

### 解释要点

- 传感器与人眼的光谱敏感度不同；
- 云、气溶胶、灯具方向和地形会改变结果；
- 因此不同数据源的变化速度可能不一致；
- 这不是必须被“修平”的误差，而是测量对象的差别。

### 视觉表现

尽量使用简洁信息图，不增加复杂滚动动画。这里是第二个注意力恢复段。

## 场景 08：五地同一天空——不同版本的宇宙

### 叙事任务

用统一规则比较不同城市或环境，避免摄影图片的曝光、天气和设备差异。

### 布局

桌面端五列或 3+2 小倍数，移动端两列：

```text
┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
│纽约   │ │深圳   │ │东京   │ │郊区   │ │暗夜   │
│星空   │ │星空   │ │星空   │ │星空   │ │星空   │
└──────┘ └──────┘ └──────┘ └──────┘ └──────┘
```

### 比较规则

- 同一天区；
- 同一时间假设；
- 同一星表；
- 同一投影；
- 只改变背景亮度和可见阈值。

### 文案重点

最先失去的不是猎户座最亮主星，而是周围大量暗星。随后星座之间原本连续的结构被切断，天空从有深度的空间退化成平面背景。

### 数据要求

首版正式发布可使用“环境类型”而不是城市精确排名；只有获得可比模型数据后，才将地点名称与具体数值绑定。

## 场景 09：生态——一盏灯改变一条路径

### 叙事任务

证明黑暗是生态环境的一部分，而不仅是审美资源。

### 主案例

夜间迁徙鸟类与高强度城市灯光。

### 布局

```text
┌──────────────────────────────────────┐
│ 夜空中的迁徙轨迹                     │
│       → → →                          │
│            ↘  ↺ 光源 ↻              │
│       → → →                          │
└──────────────────────────────────────┘
          [关闭高强度灯光]

说明文字
```

### 开灯状态

- 部分轨迹向灯光中心聚集；
- 出现盘旋和方向改变；
- 城市光穹明显。

### 关灯状态

- 轨迹逐渐恢复稳定方向；
- 光穹下降；
- 文案解释研究观察而非所有城市的通用实时模拟。

### 限制

- 不声称所有鸟类反应完全一致；
- 不将一个研究地点的效应量直接推广到全球；
- 动画只解释机制和方向。

## 场景 10：照明治理实验室——不是把城市关掉

### 叙事任务

把解决方案从口号转化为可操作的工程选择，并破除“安全与星空二选一”。

### 控件

1. 只保留有明确用途的灯光；
2. 灯具完全遮罩并向下定向；
3. 亮度不超过实际需要；
4. 无人或深夜时段自动调暗；
5. 色温滑杆。

### 布局

```text
┌──────────────────┬─────────────────────────┐
│ ☑ 明确用途        │ 天空与地面照明模拟        │
│ ☐ 向下定向        │                         │
│ ☐ 降低亮度        │  地面仍被照亮             │
│ ☐ 深夜调暗        │  向上逸散减少             │
│ 色温 [────●──]   │                         │
│                  │ 相对天空辉光：78          │
└──────────────────┴─────────────────────────┘
```

### 输出规则

可以显示“相对天空辉光示意指数”，但必须标注：

> 示意指数，不是任意城市的通用实测结果。

除非接入正式物理模型，不显示“恢复了47颗星”之类具体结论。

### 成功体验

读者应看到：

- 地面不必陷入完全黑暗；
- 改变方向和时段可显著降低无效向上光；
- 色温只是其中一项，不能替代用途、方向和亮度管理。

## 场景 11：结尾——重新观察今晚的天空

### 叙事任务

把宏大环境问题重新落回读者自己的观察。

### 视觉

恢复相对暗的星空，但不做“所有星星完全回来”的虚假圆满。画面安静、缓慢，结束时不再提供复杂控件。

### 文案

> 今晚，当你再次抬头时，不要只寻找最亮的几颗星。试着观察它们之间还有多少微弱星点，天空背景接近黑色，还是带着灰白、橙黄或蓝紫色的光。

> 我们总以为星空非常遥远。真正把它从视野中带走的，却是地面上离我们最近的光。

按钮：

- “重新看一次夜空”；
- 后续可增加“查看方法”与“分享故事”。

## 响应式要求

### 桌面端

- 地图和星空可并排；
- sticky 场景可使用 55/45 或 60/40 分栏；
- 小倍数最多五列；
- 文字宽度不因大屏无限扩张。

### 手机端

- 不依赖 hover；
- 地图与星空上下排列；
- sticky 高度控制在 65—72vh；
- 控件触控区域至少约 44px；
- 标题避免超出屏幕；
- 大型 Canvas 使用设备像素比上限，防止性能过载。

## 无障碍与性能

- Canvas 必须有 aria-label 或等价文字；
- 核心结论不能只存在于动画；
- 键盘可操作滑杆和地点按钮；
- 支持 `prefers-reduced-motion`；
- 星表与地点数据本地加载；
- 首屏资源控制体积；
- 动画使用 `requestAnimationFrame`，避免每次滚动同步重绘全部场景；
- 页面离屏 Canvas 可暂停更新。
