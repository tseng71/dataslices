# 《消失的星空》方法与不确定性 v2

> 状态：第四阶段内容与证据已确认
> 复算日期：2026-07-28

## 1. 证据分层

页面必须把五类内容区分显示：

| 类型 | 定义 | 本故事示例 |
|---|---|---|
| 观测 | 论文记录或目录条目 | BSC 星等；Globe at Night 趋势；Tribute in Light 鸟类响应 |
| 模型 | 物理或统计模型输出 | World Atlas 人工天空亮度档 |
| 推导 | 使用公开参数复算 | 18 年亮度倍数；点位模型隐含极限星等 |
| 情景 | 研究用于解释尺度的例子 | 250 颗到约 100 颗 |
| 视觉编码 | 保持叙事一致的编辑映射 | 6、12 岁阈值与中间可见数量 |

任何组件都不得把后四类静默标成“实测”。

## 2. 恒星数据与天区

数据源为 Bright Star Catalogue 第五修订版预备版（VizieR `V/50`）。脚本按固定宽度读取：

- HR 编号；
- J2000.0 赤经、赤纬；
- V 波段视星等；
- B−V 色指数；
- 光谱型；
- Bayer／Flamsteed 原始名称。

选区是矩形天区：

- 赤经：72°—94°；
- 赤纬：−11.5°—23°；
- 视星等：`Vmag <= 6.50`。

结果为 250 条目录记录。这个范围以猎户座为中心，但不表示所有星都属于猎户座，也不表示星数覆盖整个半球。多星系统可有相邻或重合的目录条目，页面保留各自 HR 身份。

平面位置用于叙事连续性：

```text
x = (94° − RA) / 22°
y = (23° − Dec) / 34.5°
```

赤经反向显示，符合常见星图方向。正式页面若加入观察时刻、方位或地平线投影，必须另行记录时间、地点和投影，不得把这个矩形坐标称为某一时刻的精确视野。

## 3. 可见阈值

目录显示规则为：

```text
visible = star.vmag <= display_threshold_vmag
```

它是视觉编码，不是完整的人眼可见性模型。肉眼极限还会受到视力、暗适应、空气透明度、云、月光、观察方向、直接眩光和遮挡影响。

视觉阈值为 `6.50、6.16、5.82、5.48`。在批准天区中分别保留 `250、194、133、100` 条目录记录。只有首末计数与论文的 250→100 示例对齐；两个中间状态不得作为观测或预测数字呈现给读者。

## 4. 18 年情景

Kyba 等（2023）报告全球天空辉光年增长率：

```text
r = 9.6% ± 0.4%
```

页面在批准年龄节点 `0、6、12、18` 计算：

```text
skyglow_factor(t) = (1 + r)^t
```

中心估计依次为：

| 年龄 | 天空辉光倍数 | 9.2%—10.0% 年率范围 |
|---:|---:|---:|
| 0 | 1.0000 | 1.0000—1.0000 |
| 6 | 1.7333 | 1.6956—1.7716 |
| 12 | 3.0042 | 2.8752—3.1384 |
| 18 | 5.2070 | 4.8754—5.5599 |

论文直接给出“原本可见 250 颗星的地点，18 年后降至约 100 颗”的解释性例子。页面不会把全球平均增长率当作纽约预测，也不会对 6、12 岁给出读者面对的精确星数。

## 5. World Atlas 点位抽样

点位来自 Falchi 等（2016）World Atlas 官方 KMZ。KMZ 内每个 JPEG 有 KML `LatLonBox`；脚本按经纬度找到覆盖瓦片，再将 WGS84 坐标转换到最近像素。

像素颜色不是连续量，而是论文表 1 的人工天空亮度／自然天空亮度分档。脚本用与地图 JPEG 对应的参考色做最近色分类，同时保存：

- 原始像素 RGB；
- 参考色 RGB；
- 色距；
- 瓦片名与像素坐标；
- 分档上下界。

路线结果：

| 点位 | 距时代广场直线距离 | Atlas 分档 |
|---|---:|---:|
| 时代广场 | 0.0 km | `>41` |
| 中央公园大草坪 | 3.0 km | `>41` |
| 牙买加湾野生动物保护区 | 20.8 km | `20.5–41` |
| 佩勒姆湾／果园海滩 | 20.8 km | `10.2–20.5` |
| 蒙托克角 | 182.2 km | `0.16–0.32` |

World Atlas 的底层 GeoTIFF 分辨率为 30 角秒，模型基线约为 2014 年，估计的是晴空天顶人工亮度。KMZ 是分档显示产品；海岸附近像素可能有 JPEG 混色，所以页面显示分档而非伪造连续值。

时代广场与中央公园在该模型中同为最高档。页面可以解释公园可能减少直接眩光、增加开阔视野，但不得把 Atlas 说成检测到了两者的局部差异。

## 6. 从 Atlas 分档推导极限星等

Kyba 等（2023）补充材料给出的北美拟合为：

```text
NELM = Nn + s × log10(B / B0)
Nn = 4.95 ± 0.02
s = −1.52 ± 0.02
residual sigma = 1.009 ± 0.008 mag
```

World Atlas 给出人工／自然亮度比 `q`，所以：

```text
B / B0 = 1 + q
```

据此得到模型隐含区间：

| Atlas 分档 | 推导 NELM |
|---:|---:|
| `>41` | `<2.48` |
| `20.5–41` | `2.48–2.92` |
| `10.2–20.5` | `2.92–3.36` |
| `0.16–0.32` | `4.77–4.85` |

这些是把两个不同来源模型连接后的推导值。约 1 星等的拟合残差已经足以跨过大量目录星；现场条件还会增加差异。因此主叙事优先显示亮度档，NELM 只作为带明显方法标签的辅助读数，不转为精确星数。

## 7. 未使用的局部观测

本数据包没有纳入点位附近的 Globe at Night 观测，相关字段保留为 `null`，覆盖状态写明“未使用局部校验”。缺少这一层证据时：

- 不把 World Atlas 档位称为现场实测；
- 不声称某个具体夜晚可以看见多少颗星；
- 不用旧版硬编码点位数值填补；
- 不用缺失记录证明“没有变化”。

后续若加入局部观测，必须记录检索窗口、半径、质量筛选、样本数和数据许可，并重新经过内容确认。

## 8. 照明比较

照明模块采用 DarkSky International 与 Illuminating Engineering Society 联合提出的五项原则：

1. 有明确用途；
2. 准确投向；
3. 不高于必要亮度；
4. 只在需要时开启或调亮；
5. 尽量减少蓝紫短波成分。

`lighting-presets.json` 是类别状态，不含灯具配光曲线、光通量、反射率或大气传播参数。因此可以显示光路方向和改变的工程维度，不可以输出天空亮度下降百分比或恢复星数。

## 9. 生态证据

生态插页只使用 Van Doren 等（2017）对纽约 Tribute in Light 的具体研究：

- 2008—2016 年的七个开启夜晚；
- 天气雷达与现场观测结合；
- 估计累计影响超过 110 万只迁徙鸟；
- 临时关灯后，鸟群在几分钟内分散。

这是高强度、临时上射光装置的事件研究。页面不得把它外推为所有鸟类、所有城市或普通路灯的统一响应。

```bash

  --catalog /path/to/V_50_catalog \
  --output-dir stories/disappearing-stars/data/v2

python stories/disappearing-stars/scripts/sample_world_atlas_kmz.py \
  --kmz /path/to/NewWorldAtlas_ArtificialSkyBrightness.kmz \
  --output stories/disappearing-stars/data/v2/nyc-places.json
```

原始大文件不进入仓库；`sources-v2.md` 和生成数据保存下载地址、日期、版本、许可与哈希。生产实现必须读取这里的 v2 数据，不得继续使用旧版 `locations.json` 和 `sky-scenarios.json`。
