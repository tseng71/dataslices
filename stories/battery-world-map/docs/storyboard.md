## Visual system

同一枚参考方形电芯贯穿全文。锂、钴、镍、锰、石墨、铜、铝、铁、磷保持固定颜色、形状和纹理；从电芯剖面移动到开采地图、加工地图、化学路线和压力测试。国家份额使用点阵、对齐份额带和排序列表共同表达，地图不单独承担精确比较。

## Exploratory state

- 默认材料：钴；
- 默认阶段：矿山，随后由叙事进入加工；
- 默认路线：NMC；
- 压力测试默认无中断；
- URL可保存 `material`、`stage`、`chemistry`、`node`；
- 无数据时显示“不可用的原因”，不以零替代；
- 数据加载失败时回退到静态结论和数据表；
- 每个互动都有文字明确的“恢复基准”。

## Ending

材料从地图返回电芯，但保留国家和加工阶段标签。结尾不宣称电池能够脱离全球供应链，而把问题转向透明、多元、效率、回收和责任。页面随后提供方法、数据以及其他 DataSlices 故事入口。
