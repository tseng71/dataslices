## 固定约束

- 同一材料在拆解、地图、化学体系和压力测试中使用同一色彩身份。
- 不把矿山产量、储量、精炼份额、贸易或规划产能混成同一序列。
- 压力测试不用“预测”“将上涨”等语言。
- 移动端地图保留排序列表，互动不依赖 hover。
