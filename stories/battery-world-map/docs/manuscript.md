# 《拆开一块电池，里面藏着一张世界地图》连续正文母稿

一块电动车电池看起来像一个封闭的工业品。外壳之内，正极、负极、隔膜与电解液紧密叠在一起；外壳之外，它的材料却从几大洲出发，经过矿山、化学转化、活性材料制造与电芯装配，才在同一处相遇。

真正决定供应链韧性的，不只是矿藏在哪里，更是材料在哪里被加工。

先把银色外壳拿开。外壳保护内部卷芯，却不是故事的终点。NMC 正极可能包含锂、镍、锰和钴；LFP 正极则以锂、铁和磷为主。今天的大多数锂离子电池仍使用石墨负极。换掉钴和镍，并不等于摆脱所有集中依赖。

地图的第一层是矿山。2025 年，澳大利亚是最大的锂矿生产国；刚果民主共和国约占全球钴矿产量的 73%；印度尼西亚约占镍矿产量的三分之二；中国约占天然石墨矿产量的八成。

第二层地图是加工。锂矿可以在澳大利亚开采，却在中国转化为电池级化学品。钴可以从刚果（金）的铜钴矿带离开，再进入别处的精炼设施。石墨从矿物变成高纯球形负极材料，还需要另一套化学与制造能力。IEA 估计，六种关键能源矿物前三大精炼国的平均份额在 2024 年达到 86%，高于 2020 年的约 82%。

一块矿石还不是一块电池。它要经过开采、精炼、活性材料制造与电芯生产。每前进一步，材料纯度、设备、知识和资本门槛都会变化。控制矿山，不等于控制下一道工序。

钴把集中度变得最直观。100 份全球钴矿中，约 73 份来自刚果（金），约 14 份来自印度尼西亚。这个国家份额不能被直接翻译成单一劳工结论：大型工业矿山与手工小矿具有不同的组织、风险与治理问题。数字在这里说明集中度，而不是给所有生产者贴同一个标签。

化学体系可以重画地图。NMC 正极把注意力放在镍、锰与钴；LFP 移走镍和钴，把铁、磷与高纯磷酸带到前景。两种路线都仍需要锂，也通常需要石墨负极。替代会降低某些暴露，同时把依赖迁移到别处。

压力测试把集中度翻译为一个更克制的问题：如果最大供应国所在环节受阻，当前路线对它暴露多少？它不预测价格，也不假装知道库存、合同、替代速度和中断持续时间。它只提醒我们，市场总体充足与供应链足够分散不是同一件事。

改善韧性没有一颗银弹。更多地区可以进入开采，但新矿需要时间、许可和社会协商；更多地区可以建设加工，但资本与工程门槛很高；新化学体系可以减少某些材料，却产生新的高纯材料需求；回收能让材料再次进入循环，但回收产能本身也高度集中，且退役电池数量需要时间积累。

最后，材料层被重新装回外壳，电池又变成一块安静的银色长方体。地图从视线中消失了，却没有从供应链里消失。下一次看到电动车、手机或储能站时，可以多问两层：矿从哪里来？谁把它变成电池级材料？

一块电池不是一个地点。它是一条被折叠起来的世界。
